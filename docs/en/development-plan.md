# Development plan

This alpha establishes the neutral import, four declared-policy checks and normalized reporting. The report can be validated, compared and rendered by opsec-report-contract. Assessment code does not modify the source or storage.

Next steps require separate acceptance: inspected vendor-export adapters, evidence-reference validation, policy provenance and isolated restore-test integrations. Each adapter needs positive, negative and unavailable cases from its actual producer structure. Credentials, deletion and automatic repair must not become hidden behavior.
