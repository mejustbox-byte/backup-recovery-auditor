# ADR: offline contract consumer

Accepted: Python 3.12+, JSON, unittest and exact opsec-report-contract 0.1.0a1. A shared report implementation prevents status and coverage semantics from drifting between auditors. Bootstrap installs the released GitHub wheel with its published SHA-256; initial installation needs network, assessment itself does not.

Build requirements pin setuptools 84.0.0 and wheel 0.48.0. CI targets Python 3.13 on Linux, Windows and macOS. Vendor SDKs, remote URLs, YAML execution tags and restore engines are excluded from this alpha. Byte hashes establish consistency, not supply-chain trust or evidence authenticity.
