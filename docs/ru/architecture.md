# Архитектура

CLI → ограниченный строгий JSON → модель с точными полями → чистые проверки → нормализованный отчёт → эксклюзивный новый файл. Выпущенный opsec-report-contract 0.1.0a1 предоставляет разбор, покрытие и валидацию выхода. Сообщения источника и учётные данные хранилища не принимаются.

Загрузчик ограничивает вход 8 MiB и глубиной 64. Лимит активов по умолчанию 1000, его можно уменьшить --max-assets. Каждый актив даёт четыре записи с уникальной парой контроль/актив. Неизвестные записи делают покрытие неполным. Общие сообщения не повторяют исходные тексты, но scope и ID могут быть чувствительными.
