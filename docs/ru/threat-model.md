# Модель угроз

Недоверенный вход может содержать повреждённый JSON, ложные настройки и приватные ID. Строгие типы, точные поля, лимиты, отказ от дубликатов и эксклюзивный выход уменьшают обычные риски. Сетевого сборщика и исполнения входа нет. Ошибки общие, без значений источника.

Остаются ложные заявления, гонки файловой системы, hardlinks, ошибки runtime/зависимостей и расход ресурсов в пределах лимитов. ID и scope не анонимизируются. Аудитор не удостоверяет запись восстановления, доступность ключей, не очищает приватность и не разрешает публикацию. Pass означает соответствие заявленной политике, а не доказательство восстановления.
