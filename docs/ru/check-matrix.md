# Матрица проверок

| ID | Pass | Fail | Неизвестность |
|---|---|---|---|
| BAK-001 | Оба флага избыточных прав false | Любой true | Null без известного отказа |
| BAK-002 | Шифрование и отдельный доступ true | Любой false | Null без известного отказа |
| BAK-003 | Неизменяемость и подтверждение true | Любой false | Null без известного отказа |
| BAK-004 | Успех с датой в пределах срока | Отказ либо устаревший успех | Нет даты или результат unknown |

Fail BAK-004 имеет severity critical, остальные — high; другие статусы — info. Ровно предельный возраст проходит, превышение на секунду — fail. Явный отказ остаётся fail даже без даты. Будущие даты отвергают вход, а не создают искусственную свежесть. Immutability_verified — предоставленное заявление, не независимое исследование политики.
