# Кандидат alpha 0.1.0a1

Реализованы четыре проверки заявлений, строгий ограниченный импорт, настраиваемый лимит активов, UTC-возраст восстановления и выход opsec-1.0. Локально прошли 19 тестовых методов в Linux/Python 3.12. Hosted CI и чистая установка фиксируются после выполнения.

Нет vendor-сборщика, фактического восстановления, удостоверения свидетельств или очистки приватности. Публикация PyPI не заявляется. Prerelease предназначен для проверяемого автономного применения, а не production-гарантий.
