# Проверки и реальное восстановление

Тесты покрывают каждый контроль, неизвестность, строгие типы, отказ/давность восстановления, точные временные границы, календарь, дубликаты, лишние поля и лимит активов. CLI отдельно проверяет коды и конфликт выхода. Публичные входы синтетические.

Настоящее восстановление выполняется в изолированной среде с приватными журналами. Точную копию, среду, оператора, доступность ключей, начало/конец и проверки целостности сохраняйте вне публичной фикстуры. Только после проверки экспортируйте нормализованное заявление. Для кандидата реальное восстановление и production-подключение не выполнялись.
