# ADR: автономный потребитель контракта

Приняты Python 3.12+, JSON, unittest и точный opsec-report-contract 0.1.0a1. Общая реализация отчёта предотвращает расхождение статусов и покрытия между аудиторами. Bootstrap устанавливает GitHub wheel с опубликованным SHA-256; первичная установка требует сеть, оценка — нет.

Сборка закрепляет setuptools 84.0.0 и wheel 0.48.0. CI нацелен на Python 3.13 в Linux, Windows и macOS. Vendor SDK, удалённые URL, исполняемые YAML-теги и движки восстановления вне alpha. Хеш подтверждает совпадение байтов, а не доверие цепочке зависимостей или подлинность свидетельства.
